# Enhanced edition changes

The initial GitHub commit imported the original ZIP. Subsequent enhanced commits rebuild the approved eight-phase implementation after the earlier cloud reset. The source is now versioned in this repository.

1. **Baseline/configuration:** dependency lock, startup validation, safe actionable database diagnostics, password byte bounds, malformed-path handling, secret-free source, same-origin serving, root command shortcuts and VS Code launch/tasks.
2. **Authentication/navigation:** shared API/session helper, guards for every internal page, stored-role routing, visible mobile sign-out, database-backed revocation, profile/password changes and secure operator tools.
3. **UI:** shared purple/lavender layout, responsive cards/navigation/forms/tables/dialogs, loading/error/retry/empty states, labels, focus, contrast and original public illustration. Removed superseded CSS/JS and disconnected sample catalogues.
4. **Assignments:** real detail/search/list/create/edit/publish/archive, requirements, marks, private resources and downloads, original-schema response defaults.
5. **Submissions/grading:** saved immutable unique submission, timestamp/late status/receipt, private download checks, bounded grading and feedback; format/size/archive validation and rejected-upload cleanup.
6. **Events:** real create/edit/publish/cancel, filtered lists/details, registration/cancellation transactions, capacity, uniqueness, My events and organizer attendees.
7. **Dashboards/admin:** real scoped counts, user listing/creation/promotion/access changes, immediate session revocation; protected admin identities.
8. **Verification/handover:** isolated API/browser tests, concurrency/permission/failure coverage, responsive/accessibility checks, screenshots, CI, architecture/model/API/setup/troubleshooting/test documentation.

No Atlas data migration, seeding, deployment or real-account provisioning was performed. Attendance, transcripts, notifications, Google sign-in and email receipts remain explicitly unavailable.
